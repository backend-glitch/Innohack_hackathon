# FloodGuard Backend

Member 2 backend scaffold for the hackathon.

## Run

```bash
npm install
npm run dev
```

## Endpoints

- `GET /api/health`
- `GET /api/weather?lat=&lng=`
- `GET /api/risk?lat=&lng=`
- `GET /api/route?from=lat,lng&to=lat,lng`
- `GET /api/shelters`
- `GET /api/alerts?lat=&lng=`
- `POST /api/sensors/simulate`
